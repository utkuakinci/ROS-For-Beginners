# Hands-on Projects

Apply what you've learned through incremental projects.

1. [Turtlesim](01-turtlesim/README.md) — Get started with basic velocity commands and telemetry using the turtlesim simulator.
2. [Obstacle Avoidance](02-obstacle-avoidance/README.md) — Use sensor data to keep a simulated robot from colliding with its surroundings.
3. [Mapping](03-mapping/README.md) — Build a 2D grid map of a simulated environment using LiDAR.
4. [Autonomous Navigation](04-autonomous-navigation/README.md) — Navigate through a series of waypoints in a simulated environment.
5. [Final Project](05-final-project/README.md) — An end-to-end project combining simulation, navigation, and manipulation.
