# 00. Prerequisites

The minimum Linux, Git, and Python knowledge you need before touching ROS 2.

## Lessons

1. [Linux Basics](linux-basics.md) — ROS 2 is developed and run primarily on Ubuntu, so comfort with the terminal is essential.
2. [Git Basics](git-basics.md) — Almost every ROS 2 package lives in a Git repository; you will clone, branch, and commit constantly.
3. [Python Basics](python-basics.md) — The Python features that `rclpy` code relies on most.
