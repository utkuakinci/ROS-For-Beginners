# 01. ROS 2 Core Concepts

The vocabulary and mental model behind every ROS 2 system.

## Lessons

1. [What is ROS 2?](what-is-ros2.md) — What ROS 2 is, what it is not, and why robotics projects use it.
2. [ROS 2 Architecture](ros2-architecture.md) — How the layers of ROS 2 fit together, from your code down to the network.
3. [Nodes](nodes.md) — Nodes are the basic unit of computation in ROS 2.
4. [Topics](topics.md) — Topics carry continuous streams of data between nodes using publish/subscribe.
5. [Services](services.md) — Services provide request/response communication for short, synchronous-style interactions.
6. [Actions](actions.md) — Actions handle long-running tasks that need feedback and can be cancelled.
7. [Parameters](parameters.md) — Parameters let you configure a node without changing its code.
8. [Launch Files](launch-files.md) — Launch files start and configure many nodes with a single command.
